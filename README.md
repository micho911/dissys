### How to Run the Tests

Test with logs, go to `peer` directory and execute:

```bash
cd peer
go test
```

Run this from the root directory with no logs:

```bash
go test ./peer
```

### How to Run the Sample Network

To run the sample network, navigate to the `main` directory and execute:

```bash
go run ./main
```
